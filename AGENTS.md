# Instructions for AI agents

## Repository language

All AI-authored repository content must be English only, including documentation, comments, docstrings, descriptions, commit messages, release notes, and pull request or issue titles, descriptions, and comments. This applies regardless of the conversation language. Chat replies may follow the user's language. Do not add parallel Russian documentation.

## Scope

This is the public `msrv-ai/.github` organization-profile repository. Read `README.md` and `profile/README.md` before editing. The rendered profile is a company introduction, not an operational runbook.

- Preserve the company name `msrv.ai`, product name `GateRook`, and official website `https://msrv.dev` unless the user changes them.
- Keep company and product descriptions grounded in approved public information and the application design kit. Do not invent contact details, customers, performance claims, certifications, licensing terms, or release availability.
- Link only to public resources from the profile. Do not expose private repository internals, deployment locations, credentials, or unpublished operational details.
- Use the canonical design-kit logo exports without redrawing or recoloring them. Keep accessible image descriptions and appropriate light/dark versions. Follow `assets/README.md` when refreshing them.
- This repository holds static publication assets only. All build, generation, validation tooling, CI, packaging, signing, deployment, and key management belong to the private platform. Do not add workflows or a duplicate design-kit source tree here.
- Keep development status accurate. Public repository visibility alone does not establish an open-source license or a released installer.
- Organization-wide community health files affect other repositories. Add them only when the user requests the corresponding policy; do not invent support commitments or legal terms.

## Verification

Check Markdown links, image rendering in light and dark themes, English text, asset provenance, and `git diff --check`. Verify the live organization Overview after publication. Preserve existing user changes and avoid unrelated organization permission or security changes.
