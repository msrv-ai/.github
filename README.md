# msrv.ai on GitHub

This repository maintains the public [msrv.ai organization profile](https://github.com/msrv-ai).

- `profile/README.md` is displayed on the organization's Overview page.
- `assets/` contains distribution copies of approved GateRook design-kit exports.
- `AGENTS.md` defines editing and language rules.

The official company website is [msrv.dev](https://msrv.dev). The featured public project is [GateRook](https://github.com/msrv-ai/gaterook).

Keep all content in English. Use verified public information and working links. Keep private build, deployment, and credential details out of this repository. This repository contains no build workflows or application source.

See [asset provenance](assets/README.md) before updating the artwork. The application design kit remains the canonical source; these files are publication assets, not a second editable design system.
