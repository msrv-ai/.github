The artwork uses the kit's Gate violet accent and outlined Inter Semibold wordmark. The icon is the existing white rook with an open gateway on a violet rounded square.

Do not edit these exports independently or introduce another source of logo geometry. Refresh them from the approved application design kit when its canonical artwork changes. Generation tooling remains with the private platform; this repository contains only the resulting public assets. No fonts, application code, or private operational files are included.
